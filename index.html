WHAT IT DOES

Useful status, with narrow access.

01

One owner’s inbox

This is a personal operations tool. It is not a public task runner, customer portal, or marketplace service.

02

One selected spreadsheet

The planned poller reads metadata and a CSV export from the owner-selected ULTRON-Command-Inbox spreadsheet. It does not browse the owner’s Drive.

03

No broad Drive browsing

The OAuth scope is drive.file. The staged poller further pins one spreadsheet and uses fixed HTTPS GET requests; the scope itself can permit changes to files authorized to the app.

i

Current availability

The command poller and separate status-report publisher have not been deployed. No live status feed, command processing, or automatic report delivery is active.

GOOGLE DRIVE ACCESS

A user-authorized, per-file permission.

Google defines drive.file as access to files a user opens or creates with an app, or explicitly makes available to it. This OAuth app is designed to read the selected command spreadsheet through fixed metadata and CSV requests. A separate service-account publisher is planned for status reports; that publisher uses a different credential and is not authorized by this user OAuth consent. The scope itself is not a Google-side guarantee that a token can access only one ID.
